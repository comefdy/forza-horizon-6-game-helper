# Original Flowcharts Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add original, copyright-safe flowcharts that make the site feel more useful to players before real gameplay screenshots are available.

**Architecture:** Reuse the existing static page generator in `scripts/generate-pages.js`. Add a data-driven `flowchartBlock` renderer that outputs semantic HTML cards, then style the diagrams in `src/styles.css`. Keep the charts lightweight and readable on mobile.

**Tech Stack:** Static HTML generated by Node.js, plain CSS, no external images or libraries.

---

### Task 1: Add Flowchart Data and Renderer

**Files:**
- Modify: `scripts/generate-pages.js`

**Steps:**
1. Add a `flowchart` object to `/pc-settings/`, `/invalid-gaming-services-detected/`, and `/how-to-play-smoothly/`.
2. Create `flowchartBlock(page)` to render steps with labels, titles and descriptions.
3. Add a Table of Contents entry when `page.flowchart` exists.
4. Insert the flowchart near the top of the content stack, before tools and extra tables.

### Task 2: Add Visual Styling

**Files:**
- Modify: `src/styles.css`

**Steps:**
1. Add a responsive `.flowchart` grid.
2. Add step number, title and arrow connector styling using CSS only.
3. Ensure text wraps cleanly on mobile.

### Task 3: Regenerate and Verify

**Files:**
- Generated: page HTML files affected by `scripts/generate-pages.js`

**Steps:**
1. Run `npm.cmd run build`.
2. Verify the three core pages contain the expected flowchart headings.
3. Start local preview and verify `/pc-settings/`, `/invalid-gaming-services-detected/`, and `/how-to-play-smoothly/` return 200.
